# alt preset: developer

## Hats
Implementation Dev, Tech Leadership, Business, UX. Name any other as a guess.

## Record and where facts usually live
The ticket, the code beside the work, and the repo's docs. Usually in the tracker, the codebase, README and docs folders, decision records, and nearby pull requests. Read the code the work touches before asking anything it answers.

## Ready means
Ready to proceed. Ready with questions means the work can start and the open items land before it merges.

## The small artifact
A spike or a prototype. When a question needs one, say which and come back.

## Words
If done now. Record: the ticket. Team message: the team message. Proceed, never build.

## Also
A call across a service or team boundary names Tech Leadership as could-help even when the developer could answer. Anything touching money, legal, safety, or identity is shared, never batched.
